# Contributing to DevBoxer

Thanks for your interest in DevBoxer! See the [README](README.md) for an overview of the project.

## Reporting bugs and requesting features

Please [open an issue](https://github.com/devboxerhub/app/issues). For bugs, include:

- What you expected to happen
- What actually happened
- Steps to reproduce
- Browser / OS / CLI version if relevant

## Asking questions

Join us on [Discord](https://discord.gg/e8ZSUWks5M) or check the [documentation](https://www.devboxer.com/docs).

## Proposing changes

- For larger changes, please open an issue first so we can discuss the approach.
- Small fixes, such as typos in the README, can go straight to a pull request.

To submit a pull request:

1. Fork the repo and create a branch.
2. Make a focused change.
3. Open a pull request with a short description of what changed and why.

## Be respectful

Please keep discussions courteous and constructive.
